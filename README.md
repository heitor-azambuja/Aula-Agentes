# Aula-Agentes

Repositório de apoio para aulas e experimentos sobre agentes de IA.

## Objetivo

Organizar materiais, exemplos e exercícios usados para estudar como agentes podem planejar tarefas, usar ferramentas, interagir com serviços externos e automatizar fluxos de trabalho.

## Conteúdo do repositório

Atualmente o repositório contém:

- `README.md`: documentação inicial do projeto.
- `LICENSE`: licença MIT do repositório.

Novos exemplos, notebooks, scripts ou materiais de aula devem ser adicionados em diretórios específicos conforme o projeto evoluir.

## Pré-requisitos

- Python 3.11 ou superior.
- `pip` para instalar dependências.

## Como usar

Clone o repositório:

```bash
git clone https://github.com/heitor-azambuja/Aula-Agentes.git
cd Aula-Agentes
```

Crie e ative um ambiente virtual:

```bash
python -m venv .venv
source .venv/bin/activate
```

Instale as dependências:

```bash
python -m pip install -r requirements.txt
```

Rode os testes:

```bash
python -m pytest
```

A aplicação completa será adicionada incrementalmente nas próximas etapas do projeto.
