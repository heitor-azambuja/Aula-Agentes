# Aula-Agentes

Repositório de apoio para aulas e experimentos sobre agentes de IA.

## Objetivo

Organizar materiais, exemplos e exercícios usados para estudar como agentes podem planejar tarefas, usar ferramentas, interagir com serviços externos e automatizar fluxos de trabalho.

## Conteúdo do repositório

Atualmente o repositório contém:

- `README.md`: documentação inicial do projeto.
- `LICENSE`: licença MIT do repositório.

Novos exemplos, notebooks, scripts ou materiais de aula devem ser adicionados em diretórios específicos conforme o projeto evoluir.

## Pré-requisitos

No estado atual, não há dependências obrigatórias para executar o projeto, pois ainda não existem scripts ou aplicações versionados neste repositório.

Quando forem adicionados exemplos executáveis, documente aqui:

- linguagem e versão necessárias;
- dependências do projeto;
- comandos de instalação;
- variáveis de ambiente, se houver;
- instruções de execução e testes.

## Como usar

Clone o repositório:

```bash
git clone https://github.com/heitor-azambuja/Aula-Agentes.git
cd Aula-Agentes
```

Leia os materiais disponíveis e acompanhe as instruções específicas de cada diretório ou arquivo adicionado ao projeto.
